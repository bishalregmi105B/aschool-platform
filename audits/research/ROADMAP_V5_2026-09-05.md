## 0. The correction that reshapes Phase C

**We do NOT rebuild the ATeacher engine inside ASchool.** W4/A read the real service
(`/Ashlya Academy Latest/ashlya_academy/ATeacher/ai_teacher/`) and Ashlya's host integration:

- The service is **single-tenant** with one static `X-API-Key` (`SERVER_API_KEY`); "tenant" appears
  nowhere in its backend. Ashlya's working host flow is **2 proxy calls** (auth/token with
  X-API-Key → session/create with Bearer) then a **query-param URL launch into the Flutter-web
  player** on its own origin — `?session_id&token&topic&user_id&autostart`. Context is pulled
  service-side from the session row, never through the URL.
- The board grammar, personas (5 DB rows), TTS, session pipeline are **the service's IP** (D2 §G
  do-not-port). The rebuilt-on-Postgres design in D1 §A.1 was wrong about what exists today; the
  shim (next section) is the honest adaptation path, and the anti-goal "no session-service rebuild"
  now also covers "no ASchool-side analyzer/planner/rooms".
- 3D/Sketchfab: **zero surface in the service — DEFERRED** (also per owner decision).

### C″-1 Shim on the service (~150 lines, the only service-side change)

`shim.py` mounted in the ATeacher Flask app + `ai_gateway.py` stream wrap:
1. `POST /api/tenants` ack (per-school key registration; host registers the plaintext at issue).
2. HMAC token endpoint (`X-ASchool-*` verified against the tenant secret it stores).
3. Session-create adapter: ASchool's payload
   `{external_lesson_id, topic, level, language, voice, persona_slug, context_document, callback_url, callback_secret_id, max_minutes}`
   → service's `{topic, level, language, voice, context, teacher_slug}` (context_document
   serialized to the ≤150k markdown-stripped text the service expects; language en/ne/mixed →
   "English/Nepali/mixed"; persona_slug → teacher_slug).
4. Event bridge: emits the 8 webhook events home (`lesson.started`, `chapter.completed`,
   `question.asked`, `mastery.updated`, `lesson.summary`, `lesson.ended`, `lesson.error`,
   `usage.reported`) signed with the callback secret — without it **nothing flows back** and our
   receiver/reconciler/cost model all starve.
5. Meter `ai_gateway.route_stream_sync` per session → real `usage.reported` (until then cost stays
   honestly `estimated`).

Deploy (W4/A2): gunicorn `--worker-class eventlet -w 1` (mandatory, in-proc sessions), port 6001,
Python 3.12, **MySQL** (pymysql; the service's own DB — never in ASchool Postgres) + Redis for
socket fan-out; rotate the Groq key committed in `render.yaml:14`; `CORS_ORIGINS` = player origin +
dashboard; compose entries `ai-teacher` (6001) + `ai-teacher-player` (nginx static of
`flutter build web --dart-define=API_BASE_URL=<service>`).

### C″-2 ASchool host adaptation (the real remaining plugin work)

1. **service_client.py rewrite**: auth HMAC→X-API-Key (or shim-side HMAC), payload remap above,
   implement `stop_lesson` against the existing `POST /api/lesson/stop` (today:
   NotImplementedError at service_client.py:120-134) and `get_session_state` poll — feeding
   poll-derived events through the same applier.
2. **Webhook-secrets hole (security fix)**: `ASCHOOL_AI_TEACHER_WEBHOOK_SECRETS` is read at
   `routes.py:589` but never populated. Fix in two halves: provisioning registers the plaintext at
   issue time (hooks.py:95-119 — it has it in memory), and an **encrypted copy** (config-secret
   envelope) is stored on `AITeacherServiceKey` and hydrated into the config map at boot —
   sha256-only can never verify HMAC.
3. **apply_event refactor**: extract the webhook body of `routes.py:578-727` into
   `apply_event(lesson, etype, payload)` so reconciler polls and webhooks share identical code.
4. **Player embed**: launcher page's `player_url` (routes.py:396-399 builds
   `{player_base}/embed#lesson=` — the service actually wants query-param launch on the player's own
   origin; fix the URL shape) + CSP `frame-src` player origin, player `connect-src`/`media-src` to
   the API, `allow="microphone"`. Socket rooms: drop our invented `lesson:{id}` host-room plan —
   rooms belong to the service (`events.py:313-320`).
5. Config schema help-text refit (language mapping, player_base_url semantics).

**Gate C″:** install → provision → configure service_base_url + player_base_url → create lesson from
published teaching_* content → student plays the embedded player with mic → results webhooks write
home (chapter/mastery/summary) → cost reconciles (`usage.reported` with shim metering) → transcripts
purge task runs. Red-team additions (injection via barge-in, self-harm escalation, off-curriculum
pivot) run against the live loop. No eval-set duplication — the 20-golden-lesson set now executes
against the real service's prompt stack, not a re-implementation.

**Kept from the aborted build (host side, already landed):** T-20 task registration + beat entries,
`token_hub.stream_request` (+ `_call_groq_stream`), B′ fixes. Removed: `services/ai_teacher/*`
rebuild (auth/engine/state).
