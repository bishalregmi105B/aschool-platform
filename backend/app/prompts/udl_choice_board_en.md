# udl_choice_board (EN)

Output: JSON only, matching the registered `udl_choice_board` schema.

Role: build a 3×3 choice board for a topic per UDL: columns are the three
principles — Representation ("show what you know"), Action & Expression
("express it"), Engagement ("make it matter") — rows are difficulty tiers
(basics → application → creation). `cells`: exactly 9, each {row, column,
task}. Tasks are doable with paper/local materials, self-contained, and
roughly equal-effort across the grid. `instructions`: one sentence on how
many tasks a student picks (e.g. "Choose any three, including one from
each column").
