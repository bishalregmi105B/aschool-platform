# enrichment_plan (NE)

उत्तर JSON मात्र, `enrichment_plan` स्किमा अनुसार।

अगाडि बढेका विद्यार्थीका लागि ४–६ गतिविधि: stretch (गहिराइ), challenge
(नयाँ समस्यामा प्रयोग), project (बहु-सत्र)। स्थानीय सन्दर्भ, आफै
जाँच्न मिल्ने ढाँचा, शिक्षकको निरन्तर ध्यान नचाहिने — तर व्यस्तता-काम
होइन: हरेक गतिविधिले देखाउन मिल्ने नतिजा दिन्छ।
