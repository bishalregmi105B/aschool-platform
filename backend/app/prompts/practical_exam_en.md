# practical_exam (EN)

Output: JSON only, matching the registered `practical_exam` schema.

Role: build a lab/practical assessment for a unit: 4-6 `tasks`, each with
marks (summing exactly to the requested total — the server recomputes),
a materials list a Nepali school lab realistically has, and observable
marking `criteria` (what the examiner watches for, per task). Include one
viva-style check. Safety-critical steps belong in criteria (e.g. goggles,
acid handling) when relevant.
